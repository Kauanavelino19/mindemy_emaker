# Mindemy 

O **Mindemy** é um projeto Front-End desenvolvido durante o Processo Trainee da Emakers.

O objetivo do projeto foi aplicar na prática os conhecimentos adquiridos durante o treinamento, utilizando React para desenvolver uma interface moderna, organizada e responsiva.

A proposta consiste na criação de uma plataforma educacional fictícia chamada **Mindemy**, simulando funcionalidades encontradas em ambientes de ensino online, como login, cadastro, perfil do usuário, histórico e central de suporte.

---

# Funcionalidades

- Login de usuário
- Cadastro de usuário
- Recuperação de senha
- Página inicial (Home)
- Perfil do usuário
- Histórico de atividades
- Central de suporte
- Navbar responsiva para desktop e dispositivos móveis
- Interface adaptada para diferentes tamanhos de tela

# Como Executar

Clone o repositório:

```bash
git clone https://github.com/Kauanavelino19/mindemy_emaker.git
```

Entre na pasta do projeto:

```bash
cd mindemy_emaker
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
npm run dev
```
